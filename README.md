# FocusList — Smart & Simple Task Manager

> A clean, responsive, frontend-only task management application designed to help users organize, prioritize, and track their daily tasks efficiently.

🔗 **Live Demo:** https://glittering-eclair-7e2389.netlify.app/

🔗 **GitHub Repository:** https://github.com/Mahima0324/Focuslist

---

## 📌 Overview

FocusList is a lightweight and responsive To-Do application built with vanilla HTML, CSS, and JavaScript.

The application focuses on making everyday task management simple by allowing users to create tasks, assign priorities, track completion, search tasks, and filter them based on their current status or priority.

All task data is stored locally in the browser using **LocalStorage**, so tasks remain available even after refreshing the page.

---

## ✨ Features

### 📝 Task Management
- Create new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Assign High, Medium, or Low priority

### 🔎 Search & Filters
- Search tasks by title
- Filter by:
  - All
  - Active
  - Completed
- Filter tasks by priority:
  - High
  - Medium
  - Low

### 📊 Productivity Statistics
FocusList automatically displays:

- **Total Tasks**
- **Completed Tasks**
- **Pending Tasks**
- **Today's Productivity Percentage**

The productivity progress updates automatically as tasks are completed.

### 💾 Persistent Storage

Tasks are stored using the browser's **LocalStorage API**, allowing task data to remain available after refreshing the page.

### 📱 Responsive Design

The interface is designed to work across:

- Desktop
- Laptop
- Tablet
- Mobile devices
